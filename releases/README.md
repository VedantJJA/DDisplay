# DDisplay Pre-Built Release Binaries

This folder contains the ready-to-run compiled binaries for both Android and Windows. You do not need to build from source or install development SDKs to use them.

---

## 1. Android App Installation

1. Copy `DDisplay-Android.apk` to your Android device (or download it directly on your phone/tablet).
2. Tap the `.apk` file on your device to install **DDisplay**.
3. Grant network and USB debugging permissions when prompted.

---

## 2. Windows Desktop App Execution

1. Open the `DDisplay-Windows-x64` folder.
2. If running for the first time, right-click `driver/install-vdd.bat` and select **Run as administrator** to install the Virtual Display Driver.
3. Launch `DDisplay.exe`.
4. Connect your Android device via USB cable (with USB debugging enabled) or over the same local Wi-Fi network.
5. Tap **Start Streaming** to use your Android device as a high-speed second display.
